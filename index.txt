      <div class="section-kicker">QUICK GUIDE</div>
      <div class="section-heading-row">
        <h2>Three steps to<br>get it online.</h2>
        <p>Use GitHub Pages to host this project for free. Make sure the homepage file is named <code>index.html</code>.</p>
      </div>
      <div class="timeline">
        <article class="timeline-item">
          <div class="timeline-marker">01</div>
          <div class="timeline-content">
            <div class="timeline-label">CREATE</div>
            <h3>Make a public repository</h3>
            <p>Sign in to GitHub and create a new public repository, for example <code>my-website</code>.</p>
          </div>
          <div class="timeline-art repo-art"><div class="repo-icon">⌂</div><span>my-website</span><small>Public repository</small></div>
        </article>
        <article class="timeline-item">
          <div class="timeline-marker">02</div>
          <div class="timeline-content">
            <div class="timeline-label">UPLOAD</div>
            <h3>Add your website files</h3>
            <p>Upload <code>index.html</code> and <code>style.css</code> to the root of the repository on the <code>main</code> branch.</p>
          </div>
          <div class="timeline-art file-art"><div class="file-chip">HTML <b>index.html</b></div><div class="file-chip css-chip">CSS <b>style.css</b></div></div>
        </article>
        <article class="timeline-item">
          <div class="timeline-marker">03</div>
          <div class="timeline-content">
            <div class="timeline-label">PUBLISH</div>
            <h3>Enable GitHub Pages</h3>
            <p>Open <strong>Settings → Pages</strong>, choose <code>main</code> as the branch and <code>/(root)</code> as the folder, then save.</p>
