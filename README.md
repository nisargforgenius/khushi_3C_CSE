# Launchpad — Static Website Practical

**Author:** Khushi Tathod  
**Class:** 3C

A responsive static website built using HTML and CSS.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling and visual design

## Run locally
Open `index.html` in any modern browser.

## Deploy with GitHub Pages
1. Create a **public** GitHub repository (for example, `my-website`).
2. Upload `index.html` and `style.css` to the repository root on the `main` branch.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the build to finish. Your URL will look like:
   `https://username.github.io/my-website/`

## Deploy with Netlify
1. Sign in at https://app.netlify.com/
2. Choose **Add new site → Deploy manually**.
3. Drag and drop this project folder.
4. Open the generated site URL.

The Google Fonts import in the HTML requires an internet connection; system font fallbacks are included.
